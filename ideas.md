## Opção A — "Organic Authority" (Biophilic Corporate)

**Design Movement:** Biophilic Design meets Corporate Minimalism

**Core Principles:**
1. Natureza como metáfora de bem-estar — formas orgânicas, texturas suaves
2. Assimetria intencional — layouts que respiram, nunca centrados
3. Hierarquia tipográfica agressiva — títulos grandes e expressivos
4. Dados como narrativa — métricas apresentadas como história visual

**Color Philosophy:**
- Fundo: branco creme quente `#FAFAF7`
- Primário: verde floresta profundo `#1A3D2B` (confiança, crescimento)
- Acento: âmbar dourado `#D4A853` (otimismo, valor)
- Texto: carvão escuro `#1C1C1E`
- Subtil: sage verde `#8FAF8A`

**Layout Paradigm:**
- Hero assimétrico: texto à esquerda, imagem app à direita com clip-path diagonal
- Secções alternadas: texto-imagem, imagem-texto, nunca centradas
- Cards flutuantes com sombras suaves e bordas arredondadas assimétricas

**Signature Elements:**
1. Formas orgânicas blob em verde sage como decoração de fundo
2. Linha divisória diagonal entre secções (clip-path)
3. Números de impacto em tipografia display bold

**Interaction Philosophy:**
- Hover suave com elevação de cards
- Scroll reveal com fade-in lateral
- CTA buttons com micro-animação de pulso

**Animation:**
- Entrance: fade-up com stagger de 0.1s entre elementos
- Hover: transform translateY(-4px) com sombra aumentada
- Números: counter animation ao entrar no viewport

**Typography System:**
- Display: Playfair Display (serif, autoridade)
- Body: DM Sans (sans-serif, legibilidade)
- Accent: DM Mono para dados/métricas

## Opção B — "Dark Precision" (Tech-Forward Health)

**Design Movement:** Dark Mode Tech Minimalism com acentos neon

**Core Principles:**
1. Escuridão como sofisticação — fundo escuro transmite seriedade
2. Dados em destaque — métricas brilham contra o fundo escuro
3. Precisão clínica — espaçamento rigoroso, alinhamentos perfeitos
4. Tecnologia visível — gradientes, glows, elementos de UI da app

**Color Philosophy:**
- Fundo: azul-marinho muito escuro `#0A0F1E`
- Primário: azul elétrico `#3B82F6`
- Acento: ciano `#06B6D4`
- Gradiente: azul para violeta `#3B82F6 → #8B5CF6`
- Texto: branco `#F8FAFC`

**Layout Paradigm:**
- Hero full-width com mockup da app flutuando
- Grid assimétrico 7/5 para secções de features
- Timeline vertical para processo de implementação

**Signature Elements:**
1. Glow effects em azul/ciano nos elementos de destaque
2. Mockup da app com reflexo/sombra dramática
3. Grid de pontos subtil como textura de fundo

**Interaction Philosophy:**
- Hover com glow border em cards
- Parallax suave no hero
- Botões com gradiente animado

**Animation:**
- Partículas flutuantes no hero
- Typing effect no headline
- Progress bars animadas para métricas

**Typography System:**
- Display: Space Grotesk (geométrico, tech)
- Body: Inter (neutro, legível)
- Dados: JetBrains Mono

## Opção C — "Warm Authority" (Human-Centered B2B) ← ESCOLHIDA

**Design Movement:** New Warmth — B2B com alma humana, inspirado em Stripe/Linear mas com calor

**Core Principles:**
1. Autoridade sem frieza — cores quentes mas profissionais
2. Storytelling visual — cada secção conta uma história
3. Contraste dramático — secções claras e escuras alternadas
4. Conversão como design — cada elemento serve o funil de leads

**Color Philosophy:**
- Fundo claro: `#FDFCF9` (quase branco, creme muito suave)
- Fundo escuro: `#0F1923` (azul-marinho quase preto, autoridade)
- Primário: `#1B4F72` (azul petróleo profundo — saúde, confiança)
- Acento: `#E8703A` (laranja coral — energia, ação, CTAs)
- Verde sucesso: `#2ECC71`
- Texto escuro: `#1A1A2E`

**Layout Paradigm:**
- Hero: split layout com fundo escuro à esquerda (texto) e claro à direita (app mockup)
- Secções alternadas claro/escuro para criar ritmo visual
- Stats em destaque com números grandes em secção escura
- Cards de testemunhos em grid irregular

**Signature Elements:**
1. Secções com fundo escuro para impacto (stats, CTA final)
2. Acento laranja coral exclusivo para botões de conversão
3. Linha de separação diagonal entre hero e conteúdo

**Interaction Philosophy:**
- Scroll suave com reveal progressivo
- Hover em cards com border laranja
- CTAs com animação de seta

**Animation:**
- Counter up para números de impacto
- Fade-in lateral ao entrar no viewport
- Floating animation subtil no mockup da app

**Typography System:**
- Display: Sora (moderno, geométrico, amigável)
- Body: Nunito Sans (legível, humano)
- Dados: Sora Bold para métricas

## Decisão Final: Opção C — "Warm Authority"

Escolhida por equilibrar profissionalismo B2B com calor humano, ideal para o target (CEOs e RH).
O contraste claro/escuro cria ritmo e impacto, enquanto o laranja coral diferencia os CTAs de conversão.
